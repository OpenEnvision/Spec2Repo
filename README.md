# Spec2Repo project page

Static site, no build step. Open `index.html` directly or serve the folder:

    python3 -m http.server 8000

- The Spec2Repo tasks and hidden tests are not publicly released. The page shows only what the paper
  reports: the leaderboard (Table 3, Table F.10), the per-task results of Appendix H, figures from the
  paper, and the `alertmanager` case of Appendix G.
- `static/js/data.js` is generated by an internal script kept outside this folder. Do not edit it by hand.
- The Paper and Code buttons in the hero are placeholders (`href="#"`, marked "soon").
